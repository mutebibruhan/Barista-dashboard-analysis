# Barista Performance Dashboard

## Project Overview
Built an Excel dashboard to analyze Barista productivity.

## Business Problem
Store teams generate large amounts of operational data, but managers often lack a clear view of productivity trends. This project transforms raw performance data into actionable insights.

## Tools Used
- Excel
- Pivot Tables
- Power Query
- 
## Metrics Tracked
- Weekly productivity trends
- Partner performance comparison
- KPI performance indicators
- Team efficiency over time

## Key Insights
- Myka-Consistently the #1 revenue partner in 3 of 4 weeks. Highest ADT (2,336) and AED 78,982 in total sales. A model for partner productivity.
- sumitrs-Near-zero in Week 17 (AED 2,732) then exploded to AED 24,899 in Week 18 — the single highest individual week by any partner. Investigate what changed.
